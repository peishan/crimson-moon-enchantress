THE CRIMSON MOON'S ENCHANTRESS (绯月妖姬) — a game adaptation by Yuchen Sky
Volume 1 = 39 comic chapters. Scripts exist for all 39 (six marked pending); comic art is in for 1-20, chapters 21-39 read as text until their art is added. Mobile-first static site (GitHub Pages), no build step.
Open index.html. Save key: crimson_moon_v1 (localStorage).

Built on the Tribute / Daybreak: Crimson Tide layout (multi-script, no framework).

scripts/characters.js  the five Season-1 heroes: classes, stats, skills + LEVEL GATES (req:{lvl,flag})
scripts/chapters.js    CHAPTER_DESIGN 1-20 (from docs/GAME_ADAPTATION_SCRIPT.md), bond banners, story flags
scripts/script.js      the short-form scripts as data (generated by tools/build_script.py from docs/GAME_ADAPTATION_SCRIPT*.md): the in-game text reader
scripts/core.js        state, save, JOIN_CH / INTRO_CH (party gates), chapter level gates, XP, bond
scripts/enemies.js     enemies, items, Wilds zones, loot
scripts/battle.js      turn-based engine
scripts/journal.js     chapters, completion, chapter battle (ch13), dev jump
scripts/storypopup.js  full-screen reader (comic art, or script text if art is missing)
scripts/savedata.js    Save tab: export/import, GitHub Gist backup, auto backup
scripts/hooks.js       200 chapter hooks (generated by tools/build_hooks.py from docs/CHAPTER_HOOKS.md + corrections); hook('id') checks a fired hook
scripts/bounties.js     the bounty board: story bounty steps and repeatable road bounties
scripts/temple.js      Ice Temple rooms from the author's map (assets/maps/ice_temple.webp)
scripts/ui.js          tabs: Journal, Party, Gates, Wilds, Temple, Cast, Training, Items, Bestiary, Save, Dev
docs/CHAPTER_GATES.md  which chapter / level gates each party member  (READ THIS)
docs/ART_ASSET_LIST.md   every art slot with exact filenames (drop-in, safe fallbacks)
docs/BONDING_AND_CURSE.md  Moon-Heat, Attunement and the Moonlit Bonding
docs/BOUNTIES.md         The Red Lantern Road bounty (V2 comic 015) and the repeatable road bounties
docs/VOLUME2.md          Volume 2 so far (comics 001-009 = chapters 40-48), the bonding pause, content notes
docs/VOLUME2_PARTY.md    Shen Cangyuan and Lu Xining: classes, skills, combinations (data only, not joinable in Volume 1)
docs/STORY_NOTES.md     SPOILERS: author's clarifications (Xiyu's origin). Not shown in the game
docs/HOOKS_REVIEW.md   the hook list checked against the scripts: corrections and open conflicts
docs/LEVEL_CURVE.md    39-chapter level curve, class curves, Yan decision, enemy scaling

COMIC ART: Volume 2 goes in assets/comics/v2/ (ch01.png = Volume 2 comic 001). Volume 1: put PNG/JPG files in assets/comics/ named by chapter: ch01.png, ch02.png ... ch20.png
(extra pages: ch01_2.png, ch01_3.png). The Pages workflow converts them to WebP on push (images taller than
15000px are sliced into pages). Until a chapter's art exists, the reader shows its script text instead.

Assets: assets/splash.webp (cover), assets/cast/season1.webp (Active Cast sheet), assets/cast/people/*.webp (20 portrait cards, scripts/people.js),
assets/party/<id>.webp (caption-free avatars cropped from the portrait set: replace with finals any time).

daily rewards, map/travel, bond skills. Scripts still missing: 25, 30, 31, 32, 35, 36 (see docs/CHAPTER_GATES.md). See docs/ART_AUDIT.md for the comic-art vs script tally.
