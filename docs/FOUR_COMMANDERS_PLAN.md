# The Four Commanders: planning (not built)

Decision: the Four Commanders should NOT become the main plot of Volume 20. They are a long-term optional mystery and a gameplay collection element, spread across volumes.

## 1. Comic: subtle foreshadowing
- An occasional mention of the four commanders.
- A mysterious reference to their missing cultivation.
- Perhaps a jewel or an old inscription appearing in the background.
- No need to explain everything immediately.

## 2. Future volumes: small side mysteries
- Each commander can be discovered in a different volume, through an optional detour or a side adventure.
- Their recovery must not interrupt the main storyline.

## 3. Gameplay: spiritual allies
The four jewels become collectible quest items. Restoring each commander could unlock:
- A spiritual companion.
- A unique combat support ability.
- Special cultivation knowledge.
- Optional dialogue or lore.

It also gives a reason to revisit locations. (Natural fit: the Wilds zones, the side cases and the informant network in docs/NETWORK.md; nothing is built yet.)

## Storyline treatment
| Storyline | Treatment |
| --- | --- |
| Xiyu's father and body exchange | Main ongoing mystery |
| Xiao Tian's origins and artifact | Major volume arc |
| Yilong forbidden craft | Short mystery arc |
| Four commanders | Distributed side mystery / gameplay addition |

This keeps the Four Commanders as worldbuilding without forcing another large mystery into the main narrative.
